# ProfitRig identity asset package

## Asset families

- `mark/`: existing charging bison SVG and PNG files, moved without changing their bytes or design.
- `wordmark/`: production wordmark pending final vectorization; see `PENDING.md`.
- `lockup/`: production lockups pending the approved vector wordmark; see `PENDING.md`.
- `references/`: approved Option 01 visual sheet, original bison reference images, and identity rules.

Read `references/IDENTITY_REFERENCE.md` before any identity work. The approved wordmark is custom Option 01 geometry, not typeset Montserrat. No font substitution is permitted.

This package is organized, but the production wordmark and lockup asset sets are NOT complete. No placeholder SVGs or enlarged screenshot PNGs have been labeled as production assets. Incorrect earlier attempts remain outside this package in `../references/archive/superseded-typography/` and must not be used.
