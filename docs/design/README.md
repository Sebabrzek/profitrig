## Typography — no substitutions

- Wordmark: official Option 01 custom asset only. Do not recreate it by typesetting Montserrat or another font.
- Headings, navigation, buttons, card titles, short UI emphasis: Satoshi.
- Body, descriptions, helper text, forms, longer reading: Inter.
- Important financial KPIs/data: JetBrains Mono.
